2. STEP-BY-STEP IMPLEMENTATION (QUICK START)
================================================================================

STEP 1: Add a wrapper div in HTML
------
Current HTML structure:
    <div class="map-container">
        <svg ...>...</svg>
    </div>

Change to:
    <div class="map-container">
        <div class="svg-wrapper">
            <svg ...>...</svg>
        </div>
    </div>

This wrapper div will contain the SVG and be transformed for zooming.


STEP 2: Add CSS for the wrapper
------
Add this to your styles.css file:

    .svg-wrapper {
        transform-origin: center;
        transition: transform 0.3s ease;
        display: inline-block;
        width: 100%;
        height: 100%;
    }


STEP 3: Add zoom functionality to JavaScript
------
Add this code to the END of your script.js file:

    // Zoom Variables
    let currentZoom = 1;
    const zoomStep = 0.1; // Each click increases/decreases by 10%
    const minZoom = 0.5;  // Minimum zoom level (50%)
    const maxZoom = 3;    // Maximum zoom level (300%)

    // Get the SVG wrapper element
    const svgWrapper = document.querySelector('.svg-wrapper');

    // Zoom In Function
    function zoomIn() {
        if (currentZoom < maxZoom) {
            currentZoom += zoomStep;
            applyZoom();
        }
    }

    // Zoom Out Function
    function zoomOut() {
        if (currentZoom > minZoom) {
            currentZoom -= zoomStep;
            applyZoom();
        }
    }

    // Apply zoom to the SVG wrapper
    function applyZoom() {
        if (svgWrapper) {
            svgWrapper.style.transform = `scale(${currentZoom})`;
        }
    }

    // Add event listeners to buttons
    if (zoomin) {
        zoomin.addEventListener('click', zoomIn);
    }

    if (zoomout) {
        zoomout.addEventListener('click', zoomOut);
    }

4. METHOD 2: USING SVG VIEWBOX (ADVANCED)
================================================================================

Why Choose This Method:
✓ More "native" SVG approach
✓ Better control over visible area
✓ Can work well with pan functionality
✗ Requires more complex calculations
✗ Harder to combine with other transforms

How SVG ViewBox Works:
The viewBox attribute defines the coordinate system. Changing it effectively
zooms the content.

Original ViewBox: viewBox="0 0 2000 857"
- Means the SVG shows coordinates 0-2000 horizontally, 0-857 vertically

To Zoom In:
- Reduce the viewBox width/height to show a smaller area
- Center on a specific point

Implementation:

    // Zoom using ViewBox
    let currentZoom = 1;
    const zoomStep = 0.15;
    const minZoom = 0.5;
    const maxZoom = 3;
    const svgElement = document.querySelector('svg');
    const originalViewBox = "0 0 2000 857";
    const viewBoxParts = originalViewBox.split(' ').map(Number);
    const originalWidth = viewBoxParts[2];
    const originalHeight = viewBoxParts[3];

    function zoomInNative() {
        if (currentZoom < maxZoom) {
            currentZoom += zoomStep;
            applyViewBoxZoom();
        }
    }

    function zoomOutNative() {
        if (currentZoom > minZoom) {
            currentZoom -= zoomStep;
            applyViewBoxZoom();
        }
    }

    function applyViewBoxZoom() {
        const newWidth = originalWidth / currentZoom;
        const newHeight = originalHeight / currentZoom;
        const offsetX = (originalWidth - newWidth) / 2;
        const offsetY = (originalHeight - newHeight) / 2;
        
        const newViewBox = `${offsetX} ${offsetY} ${newWidth} ${newHeight}`;
        svgElement.setAttribute('viewBox', newViewBox);
    }

    if (zoomin) zoomin.addEventListener('click', zoomInNative);
    if (zoomout) zoomout.addEventListener('click', zoomOutNative);

5. METHOD 3: MOUSE WHEEL ZOOM (ENHANCEMENT)
================================================================================

Add this to script.js for smooth mouse wheel zooming:

    // Mouse wheel zoom functionality
    let wheelZoomEnabled = true;
    const wheelZoomStep = 0.05;

    if (document.querySelector('.map-container')) {
        document.querySelector('.map-container').addEventListener(
            'wheel',
            function (event) {
                if (!wheelZoomEnabled) return;
                
                event.preventDefault();
                
                if (event.deltaY < 0) {
                    // Scroll up = zoom in
                    currentZoom = Math.min(currentZoom + wheelZoomStep, maxZoom);
                } else {
                    // Scroll down = zoom out
                    currentZoom = Math.max(currentZoom - wheelZoomStep, minZoom);
                }
                applyZoom();
            },
            { passive: false }
        );
    }

Notes:
- Use preventDefault() to stop page scrolling
- passive: false is required for preventDefault() in wheel events
- Adjust wheelZoomStep for sensitivity (0.02 slow, 0.1 fast)

8. TROUBLESHOOTING
================================================================================

Issue: Zoom buttons don't work
Fix:
  - Check browser console for errors (F12)
  - Verify event listeners are added: console.log(zoomin, zoomout)
  - Ensure svg-wrapper div exists in HTML
  - Check CSS isn't overriding transforms

Issue: Map looks blurry when zoomed
Fix:
  - This is CSS scaling behavior (normal)
  - For crisp scaling, use viewBox method instead
  - Or accept slight blur for simplicity

Issue: Can't click countries after zooming
Fix:
  - Ensure overflow: hidden on map-container (not auto)
  - Check pointer-events aren't disabled on wrapper
  - Verify event bubbling isn't blocked

Issue: Zoom jumps instead of smoothly transitioning
Fix:
  - Add/increase transition duration in CSS:
    .svg-wrapper {
        transition: transform 0.5s ease; /* Increase from 0.3s */
    }

Issue: Mouse wheel zoom is too sensitive
Fix:
  - Reduce wheelZoomStep value: try 0.02 or 0.03 instead of 0.05

Issue: Zoom buttons buttons are hard to see/use
Fix:
  - Enhance button styling (see section 3, Zoom Button Styling)
  - Add icons or emojis to buttons
  - Add visual feedback on hover/active
